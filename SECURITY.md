# Security Policy

Please do not publish credentials, private host inventories, raw audit logs, or
other sensitive evidence in a public issue.

For now, security reports should be sent privately through GitHub's private
vulnerability reporting feature if it is enabled for this repository. If that
feature is unavailable, open a public issue containing only a request for a
private contact channel and no vulnerability details.

This repository currently contains governance documents only. It does not
publish or deploy AppArmor policy.
